Cách sắp xếp file Word

Mỗi câu hỏi nên viết theo mẫu sau:

Câu 1: UML là gì?
A. Ngôn ngữ mô hình hóa thống nhất *
B. Hệ điều hành
C. Ngôn ngữ lập trình
D. Framework

Cách đánh dấu đáp án đúng:

  • Thêm dấu * ở cuối đáp án đúng.
  • Hoặc viết một dòng riêng: Đáp án: A.
  • Mỗi đáp án bắt đầu bằng A., B., C., D..
  • Mỗi câu hỏi bắt đầu bằng Câu 1:, Câu 2: hoặc 1., 2..

Ví dụ dùng dòng đáp án riêng:

Câu 2: HTML dùng để làm gì?
A. Tạo cấu trúc trang web
B. Thiết kế cơ sở dữ liệu
C. Chạy hệ điều hành
D. Nén file
Đáp án: A
